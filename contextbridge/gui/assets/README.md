# Artwork folder

Drop an SVG here with one of these exact names and the app uses it instead of the
placeholder drawing. No code changes needed. See `docs/GUI_ASSETS.md` for sizes and tips.

| File | Where it appears |
|---|---|
| `app_icon.svg` | The app icon, the sidebar logo, and the window icon |
| `welcome.svg` | The first screen, and the "set this project up first" prompts |
| `notes.svg` | The Notes screen when there are no notes yet |
| `changes.svg` | The Changes screen when nothing has changed yet |
| `done.svg` | The "Handoff written" screen |
| `icon_home.svg`, `icon_notes.svg`, `icon_changes.svg`, `icon_handoff.svg`, `icon_settings.svg` | The sidebar navigation |
